# Git Amaliy Topshiriq

Git va GitHub bo'yicha amaliy topshiriq uchun tayyorlangan oddiy, chiroyli va responsiv veb sahifa. Loyiha bitta `index.html` faylidan iborat bo'lib, unda HTML va CSS yordamida topshiriq shartlari vizual tarzda ko'rsatilgan.

## Loyiha Haqida

Ushbu sahifa Junior platformasidagi amaliy vazifa asosida yaratildi. Maqsad - repository yaratish, loyihani GitHub'ga joylash, hamkorlik qilish va yakuniy ishni deploy qilish jarayonlarini mashq qilish.

## Texnologiyalar

- HTML5
- CSS3
- Responsive dizayn
- Git va GitHub

## Imkoniyatlar

- Toza va sodda interfeys
- Mobil qurilmalarga moslashuvchi dizayn
- CSS yordamida yaratilgan illustratsiya
- Amaliy topshiriq bosqichlarini tartibli ko'rsatish

## Ishga Tushirish

Loyihani kompyuteringizga yuklab oling:

```bash
git clone <repository-url>
```

Loyiha papkasiga kiring:

```bash
cd <repository-folder>
```

`index.html` faylini brauzerda oching.

## Topshiriq Bosqichlari

1. Repository yaratish.
2. Loyihani terminal orqali GitHub'ga yuklash.
3. 2 yoki 3 do'stni collaboration orqali taklif qilish.
4. Jamoa bilan loyiha ustida ishlash.
5. Loyihani Netlify'ga deploy qilish.

## Muallif

Ushbu loyiha Git amaliy topshirig'i uchun tayyorlandi.
